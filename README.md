# Прогнозирование отказов оборудования с помощью ML

## 📌 О проекте

**Цель:** Разработка системы предиктивного обслуживания, прогнозирующей вероятность выхода оборудования из строя.

**Ключевые особенности:**
- Бинарная классификация (отказ/исправность)
- Интерактивный веб-интерфейс на [Streamlit](https://streamlit.io/)
- Сравнение нескольких ML-моделей
- Визуализация результатов анализа

## 🛠️ Технологический стек

| Категория           | Технологии                                       |
|---------------------|--------------------------------------------------|
| Язык                | Python 3.10+                                     |
| ML-фреймворки       | scikit-learn, XGBoost                           |
| Анализ данных       | pandas, NumPy                                   |
| Визуализация        | Matplotlib, Seaborn, Plotly                     |
| Веб-интерфейс       | Streamlit                                        |
| Деплой              | Docker, Streamlit Cloud                          |

## 📊 Данные

**Датасет:** AI4I 2020 Predictive Maintenance Dataset  
**Объем:** 10,000 записей  

**Признаки:**
- Температурные параметры (воздуха и процесса)
- Параметры работы оборудования (скорость, крутящий момент)
- Показатели износа инструмента

**Целевая переменная:** `Machine failure` (0/1)

## 🚀 Функционал приложения

### Основные страницы:
- **Анализ и моделирование**
- **Загрузка и предобработка данных**
- **Обучение моделей:**
  - Логистическая регрессия
  - Случайный лес
  - Градиентный бустинг (XGBoost)

- **Оценка качества моделей**
- **Визуализация результатов**
